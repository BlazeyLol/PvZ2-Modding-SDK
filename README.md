# PvZ2 Modding SDK (WIP)

-- This project is not dead! I am still working on it. --

A modern Plants vs. Zombies 2 hooking library with modding in mind.

## Summary
This project mimics and improves upon PopCap's style of coding, combining modern and legacy practices. The main goal is to make the modding much more user friendly, especially for people who do not know Reverse Engineering. The project is self-contained - you don't need any external dependencies (if we don't count the obvious necessities like Android NDK), and the user should be able to code most things without having to worry about having to inspect the original binary.
